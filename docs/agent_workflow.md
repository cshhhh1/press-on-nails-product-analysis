# Agent 协作流程

本项目把 Agent 当作分析执行与整理助手，关键的研究范围、抽样边界和产品判断由项目负责人确认。

## 任务拆分

1. **数据检查：**明确输入文件、关键字段和检查条件；让 Agent 辅助编写 Python 检查脚本，输出缺失、重复、日期范围和关联情况。
2. **商品与评论处理：**把商品筛选、评论关联和星级分层抽样拆开执行；让 Agent 生成或调试脚本，并保留源表原始索引。
3. **评论主题整理：**让 Agent 汇总人工编码结果、生成主题统计和需要回查的条目；人工阅读英文原文，检查主题和情感判断。
4. **竞品与方案：**让 Agent 汇总 28 件价格范围、10 件详情页信息和主题对照表；人工区分页面宣称与已验证信息，再决定 A/B 方案和测试优先级。

## 复核职责

- 项目负责人确认商品范围、统计分母和抽样规则。
- 人工复核评论原文、代表性证据、重要计数和商品纳入状态。
- 方案中的配置与价格定位作为待验证假设；Agent生成的文字不作为产品效果证据。

简历表述可概括为：“将数据质检、评论抽样与竞品核对拆解为任务，使用 Agent 辅助编写和运行 Python 脚本、整理分析表与异常清单；本人确认分析口径、复核评论原文并判断产品方案。”
