# Power BI 展示方案

建议保留两页，分别呈现两个数据时期与分析目的。不要把历史评论与当前竞品拼成连续时间趋势。

## 页面一：当前竞品价格与规格

- **价格范围：**使用 30 条快照的纳入状态筛选 28 件目标商品；展示最低 4.48、美金中位 12.99、最高 17.99，以及价格分布图。角落标注“榜单快照 2026-10-21；目标商品 n=28”。
- **规格细节：**仅对 10 件详情核对商品展示片数及尺码数、长度、形状、页面标注材质、配件和页面宣称；角落标注“详情核对 n=10”。
- **交互：**选中某个商品时，在下方明细表显示 ASIN、快照价格、片数及尺码数、长度、形状、材质文案、配件、评分、评分数和来源链接。
- **注意：**“片数”与“尺码数”是不同字段；没有明确写尺码数的页面保留为未说明。页面宣称不是实测效果。

## 页面二：历史评论主题与情感

- **主题图：**按主要主题展示 95 条人工阅读评论的计数；可用堆叠横条按负面、混合、正面及其他情感拆分。
- **样本说明：**角落注明“95 条定向分层阅读评论，覆盖 16 件历史商品；优先抽取低星评论；每条只计一个主要主题”。
- **可见发现：**厚薄与耐用 22 条；尺寸与贴合 16 条；粘性与脱落 16 条。这是样本中的主要主题数，不是品类投诉率。
- **交互：**点击主题查看标注概括、评论星级与源表原始索引。原始评论明细仅保存在本地项目文件，不包含在此 GitHub 仓库的数据输出中。
